🔧 Yeni kanal eklendikten sonra

Yeni kanal ekledin, ama YouTube'a yükleme yapabilmesi için OAuth token'ı oluşturup Railway'e ekleyeceksin.

  1. Lokal makinende proje klasörüne gir, eski token dosyasını silme. Sadece yeni token üret: 
    python -c "from services.youtube import get_youtube_service; get_youtube_service('yeni-kanal-id')"
  2. Tarayıcı açılır. Yeni marka kanalını seç, izinleri onayla. token_<id>.json dosyası oluşur.
  3. Yeni token'i base64'e çevir: 
    python -c "import base64; print(base64.b64encode(open('token_yeni-kanal-id.json','rb').read()).decode())"
  4. Çıkan base64 değerini kopyala. Railway → Variables → yeni variable:
    TOKEN_YENI_KANAL_ID
  5. Railway redeploy eder, yeni kanal aktif olur.
