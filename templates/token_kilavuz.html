Token yenileme
kılavuzu

YouTube otomasyonun "invalid_scope" veya "invalid_client" hatası verdiğinde — adım adım, panik yok.

// kısa özet

Otomasyonda token sorunu varsa refresh_tokens.py'i çalıştır → script iki kanal için yeni token üretir, base64'lerini ekrana yazar → onları Railway'e yapıştırırsın.

Toplam süre: ~1 dakika + 2 tarayıcı tıklama + 2 kopyala-yapıştır.

/01

Bu kılavuzu ne zaman kullanırım?

Railway Deploy Logs'da şu hatalardan birini görüyorsan:

railway logs / hata örnekleri
[ERROR] Token yenilenemedi (burc): ('invalid_scope: Bad Request', ...)
[ERROR] Token yenilenemedi (onelineadayy): ('invalid_grant', ...)
RuntimeError: ❌ 'burc' için YouTube token eksik/geçersiz.

Bu hatalar ya Google'ın token'ı iptal ettiğini, ya OAuth client'ının değiştiğini, ya da scope'ların uyuşmadığını gösterir. Hepsinin çözümü aynı: token'ı yeniden üret.

/03

Script'i çalıştır

1

Komutu çalıştır

cmd

2

BURÇ için onayla

Script "BURÇ için token üretiliyor" yazınca → Enter.

Tarayıcı açılır → Burç kanalının Google hesabıyla giriş yap → "Google bu uygulamayı doğrulamadı" çıkarsa Gelişmiş ayarlar → Burç Agent uygulamasına git (güvenli değil) → yetkileri onayla.

/04

Railway'e yapıştır

/05

Sorun çözme

"token_burc.json bulunamadı" diyor

Normal — script eski token dosyasını siler ve yenisini oluşturur. Bu mesaj sadece bilgilendirme amaçlı, hata değil.

"The provided client secret is invalid" diyor

GCP'de OAuth client'ı silmiş veya secret reset etmişsin. Çözüm:

1. GCP Credentials → yeni OAuth Client ID oluştur (Desktop app).

2. JSON'u indir, içeriğini üç dosyaya birden yaz: client_secrets.json, credentials_burc.json, credentials_onelineadayy.json.

3. refresh_tokens.py'i tekrar çalıştır.

Tarayıcı yanlış hesaba gidiyor

İki çözüm:

1) Komutu çalıştırmadan önce accounts.google.com'a gidip çıkış yap.

2) Tarayıcıda gizli pencere aç, orada Google'a doğru hesapla giriş yap, sonra script'i çalıştır.

"refresh_token revoked" hatası

Google hesabında uygulamanın yetkisi iptal edilmiş. Çözüm:

1. myaccount.google.com/permissions → ilgili Google hesabıyla giriş.

2. Burç Agent'i bul → Erişimi kaldır.

3. Script'i tekrar çalıştır — yeni yetki isteyecek.

"Google bu uygulamayı doğrulamadı" uyarısı çıkıyor

Bu normal. Sen kendin oluşturduğun OAuth client'ı kullanıyorsun, Google bunu "doğrulanmamış" sayıyor. Yapacağın:

1. Gelişmiş ayarlar linkine tıkla.

2. Burç Agent uygulamasına git (güvenli değil)'e tıkla.

3. Devam et.

Bu uyarı sadece "kendi yazdığın uygulama" için çıkar, gerçekten güvensiz değil.

Deploy hâlâ "invalid_scope" hatası veriyor

Büyük ihtimalle credentials_*.json dosyalarındaki client ile Railway'e yapıştırdığın token'ın client'ı uyuşmuyor. Yani token bir client'a aitken, Railway başka client_secret kullanıyor.

Çözüm: credentials_burc.json ve credentials_onelineadayy.json'un her ikisinin de aynı, güncel OAuth client bilgisini içerdiğinden emin ol — sonra script'i tekrar çalıştır.
